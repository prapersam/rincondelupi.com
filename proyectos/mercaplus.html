MercaPlus

Diseño e implementación de una infraestructura informática corporativa completa.

Proyecto de infraestructura para una empresa ficticia del sector de la distribución y venta de productos de alimentación, desarrollado como proyecto final de Grado Superior.

Infraestructura Redes Seguridad Windows Server Linux Virtualización
INFRASTRUCTURE NETWORK SECURITY SYSTEMS
01
EL PROYECTO

Una infraestructura diseñada desde cero.

MercaPlus nace como una propuesta de infraestructura tecnológica para una empresa ficticia dedicada a la distribución y venta de productos de alimentación.

El objetivo fue diseñar una infraestructura corporativa completa, segura y escalable, capaz de centralizar la administración de usuarios y equipos, proporcionar servicios internos y publicar servicios accesibles desde Internet.

La solución se estructura mediante segmentación de red con VLANs, seguridad perimetral, servicios centralizados, servidores Linux y Windows y mecanismos de monitorización, copias de seguridad y contingencia.

TIPO TFG / Proyecto final
ENTORNO Infraestructura virtualizada
SEGMENTACIÓN 5 VLANs
SISTEMAS Windows + Linux
SEGURIDAD pfSense + VLANs + VPN
